# Letter name audio

The 28 clips in this folder say the name of each hijaiyah letter (alif, ba', jim...).

- **Author:** Ruaa GHAREEB, via Wikimedia Commons
- **Licence:** [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/) (CC BY-SA 4.0)
- **Changes:** converted from stereo WAV to mono AAC (64 kbps), volume levelled to about -16 dB with a peak limiter. The words spoken are unchanged.

Under the ShareAlike terms, these modified clips are also released under CC BY-SA 4.0. This applies only to the audio files in this folder, not to the rest of Wird.

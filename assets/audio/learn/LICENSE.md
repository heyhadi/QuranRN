# Learn to Read Audio Licenses

## 1. Vowel Syllables (Fathah, Kasrah, Dammah)
The 84 clips across `fathah/`, `kasrah/`, and `dammah/` provide the vowel pronunciations for all 28 Hijaiyah letters.

- **Dataset:** Marked Hijaiyah Letters' Pronunciation Dataset
- **Authors:** Untari Novia Wisesty, Adiwijaya, Mohamad Syahrul Mubarok, et al. (Telkom University)
- **Repository:** Telkom University Open Science Dataverse
- **DOI:** [10.34820/FK2/XACWLX](https://doi.org/10.34820/FK2/XACWLX)
- **Licence:** [Creative Commons Zero 1.0 Universal (CC0 1.0) Public Domain Dedication](https://creativecommons.org/publicdomain/zero/1.0/)
- **Processing:** Selected native pronunciations, converted from uncompressed WAV to AAC mono (64 kbps, `.m4a`), peak-normalized for mobile clarity.

Under CC0 1.0 Universal, this audio is dedicated to the public domain and can be copied, modified, distributed, and used commercially and non-commercially without copyright restrictions.

## 2. Letter Names
The 28 clips in `names/` say the isolated alphabet name of each Hijaiyah letter.

- **Author:** Ruaa GHAREEB, via Wikimedia Commons
- **Licence:** [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/) (CC BY-SA 4.0)
- **Processing:** Converted from stereo WAV to mono AAC (64 kbps), peak-limited. Spoken words unchanged.

## 3. Quranic Word Recitations
The 16 clips in `words/` provide word-by-word recitations for Level 5 Quran reading lessons.

- **Reciter:** Sheikh Mahmoud Khalil Al-Husary
- **Source:** Quran.com Open Data API / CDN (`audio.qurancdn.com/wbw/`)
- **Status:** Public religious Quranic recitation, converted to mono AAC (64 kbps, `.m4a`) for offline access.

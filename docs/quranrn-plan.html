Design system

Mushaf green, brass and paper

Today the app uses plain "green" and a few hex values scattered across files. The redesign uses one token set with light and dark values. Green carries the brand and the reading state. Brass is kept for things that mark place and progress: ayah markers, Surah numbers, streaks. This page uses the same tokens, so switching your system theme shows the app's dark mode.

Tajweed colours

Rule names come from quran.com's text_uthmani_tajweed markup (17 classes found in Al-Baqarah). Colours follow the quran.com convention, adjusted so each one reads on both light and dark backgrounds. Select a rule to read its explanation. The app shows the same text when you tap a coloured letter.

Reciters

Reciter library

Only reciters with per-ayah files are included, because ayah highlighting, repeat and hifz mode depend on them. Each one is a single entry in reciters.ts mapping to a URL template. Before shipping, every reciter is checked against the first and last ayah of all 114 Surahs.

Decisions and open questions

Before building

Name: WirdStore name "Wird Quran", subtitle "Quran, Tajweed & Hifz" / "Al-Quran, Tajwid & Hafalan". No app named Wird was found, but other apps use "wird" as a feature name. Before release: check the stores directly, trademarks (PDKI, USPTO) and domains.
Development build, not Expo GoWidgets, background audio, lock-screen controls, MMKV and offline downloads all need native modules. Running locally needs Xcode or Android Studio, or EAS cloud builds.
Fully bilingualThe app follows the device language, which can be changed in Settings. Every feature works in Indonesian and English; no screen is Indonesian-only.
Tajweed explanations need reviewNo API provides them, so I'll write them for the app in both languages. Someone who knows tajweed should check them before release.
Reciter tiles, not photosEach reciter is shown by the Arabic name listeners know them by, in Kufi on a faint eight-point star. No photo rights are needed, and it stays readable at small sizes.
Islam SobhiPopular, but no per-ayah source was found. Add him for whole-Surah playback only, or wait for a source.
Not planned nowCloud sync and accounts. AI-generated tafsir; if it's ever added, it must quote real tafsir text and name the source.
